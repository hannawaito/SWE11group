# Use Case Descriptions

---

## 1. 회원가입

| Actor action                                                                        | System response                                                     |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
|                                                                                     | 1. ID, 비밀번호, 이름, 전화번호, 이메일을 입력창을 화면에 보여준다. |
| 2. 사용자는 ID, 비밀번호, 이름, 전화번호, 이메일을 입력하고 가입하기 버튼을 누른다. |                                                                     |
|                                                                                     | 3. 회원가입 완료 메시지를 팝업창으로 표시한다.                      |

---

## 3. 로그아웃

| Actor action               | System response                                          |
| -------------------------- | -------------------------------------------------------- |
|                            | 1. 로그아웃 안내 문구와 취소와 로그아웃 버튼을 보여준다. |
| 2. 로그아웃 버튼을 누른다. |                                                          |
|                            | 3. 로그아웃 완료 메시지를 팝업창으로 표시한다.           |

---

## 7. 설문 조회

| Actor action             | System response                           |
| ------------------------ | ----------------------------------------- |
|                          | 1. 등록된 설문 리스트를 보여준다.         |
| 2. 설문 하나를 선택한다. |                                           |
|                          | 3. 팝업 창으로 설문 상세 내용을 보여준다. |

> **추가기능**
> 설문 리스트 조회 화면에서 특정 설문 항목을 선택해서 삭제할 수 있다.
