

## UC5 설문 등록

| Actor action                           | System response                                      |
| -------------------------------------- | ---------------------------------------------------- |
|                                        | 1. 설문 제목 텍스트 필드를 표시한다.                 |
| 2. 설문 제목을 입력한다.               |                                                      |
|                                        | 3. 설문 설명 텍스트 필드를 표시한다.                 |
| 4. 설명을 입력한다.                    |                                                      |
|                                        | 5. 설문 시작 시각과 마감 시각 리스트를 보여준다.     |
| 6. 시작 시각과 마감 시각을 선택한다.   |                                                      |
|                                        | 7. 설문 문항 및 응답 항목 입력 필드를 표시한다.      |
| 8. 설문 문항과 응답 항목을 입력한다.   |                                                      |
| 9. 문항 추가 버튼을 눌러 문항을 추가한다. |                                                   |
| 10. 등록 버튼을 누른다.                |                                                      |
|                                        | 11. 설문 등록 완료 메시지를 팝업창으로 표시한다.     |

## UC8 설문 응답

| Actor action                           | System response                                          |
| -------------------------------------- | -------------------------------------------------------- |
|                                        | 1. 설문 응답 항목들을 체크 박스로 화면에 보여준다.       |
| 2. 항목들의 체크 박스를 선택한다.      |                                                          |
|                                        | 3. 응답 완료 버튼을 표시한다.                            |
| 4. 응답 완료 버튼을 누른다.            |                                                          |
|                                        | 5. 응답 제출 문구를 팝업 창으로 보여준다.                |

## UC11 설문 검색

| Actor action                                                      | System response                                      |
| ----------------------------------------------------------------- | ---------------------------------------------------- |
|                                                                   | 1. 진행 중, 예정, 종료 버튼을 표시한다.              |
| 2. 회원은 진행 중, 예정, 종료 중 하나를 선택해 버튼을 누른다.    |                                                      |
|                                                                   | 3. 텍스트 필드로 키워드 입력 칸을 표시한다.          |
| 4. 키워드를 입력한다.                                             |                                                      |
|                                                                   | 5. 검색 결과로 조건에 맞는 설문 리스트가 출력된다.   |
