# Use Case Descriptions (step by step breakdown)


### 4. 회원탈퇴
| Actor Action             | System Response        |
| ------------------------ | ---------------|
|     | 1. 회원탈퇴 시 안내 사항과 회원탈퇴 버튼, 취소 버튼을 보여준다. |
| 2. 회원탈퇴 버튼을 누른다. |       |
|        | 3. 회원탈퇴 완료 메시지를 팝업창으로 보여준다. |



### 6. 설문 상세 조회
| Actor Action            | System Response       |
| ------------------------ | ---------------|
|     | 1. 설문 제목, 설문 설명, 설문 문항, 응답 항목, 설문 시작 시각, 설문 마감 시작 등을 보여준다. |



### 8. 응답 조회
| Actor Action            | System Response       |
| ------------------------ | ---------------|
|    | 1. 회원이 응답한 모든 각각의 설문에 대해 설문 제목, 응답 내용, 응답 일시 등을 보여준다. |
- Extensions
    - 1번 단계 이후, 회원은 현재 진행 중인 설문에 대해서는 응답을 취소할 수 있다.
