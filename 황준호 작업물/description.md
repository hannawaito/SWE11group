## 로그인
| Actor action | System response |
| :--- | :--- |
| | 1. ID와 비밀번호를 적을 입력창을 화면에 보여준다. |
| 2. 사용자는 ID와 비밀번호를 입력한다. | |
| | 3. 로그인 성공 메시지를 팝업창으로 출력한다. |


## 응답 수정
| Actor action | System response |
| :--- | :--- |
| | 1. 설문내용과 최근 수정 날짜를 표시한다. |
| 2. 설문 수정을 완료하고 수정 버튼을 누른다. | |
| | 3. 수정 완료 메시지를 팝업창으로 출력한다. |

## 통계 조회
| Actor action | System response |
| :--- | :--- |
| | 1. 최근 1주일, 1개월, 1년 버튼을 표시한다.  |
| 2. 최근 1주일, 1개월, 1년 중 하나를 선택해 버튼을 누른다. | |
| | 3. 기간에 맞는 전체 설문 수, 종료된 설문 수, 총 응답 수를 텍스트로 출력한다. |
